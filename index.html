Luna Moretti

Ferramentas para criadores de conteúdo

Sobre o projeto

O projeto Luna Moretti tem como objetivo desenvolver ferramentas para organizar e analisar informações de vídeos e perfis do TikTok, respeitando as permissões concedidas pelos titulares das contas.

Como funciona

A proposta é utilizar integrações autorizadas para consultar informações disponibilizadas pelo TikTok e apoiar a organização e a análise de conteúdos digitais. Os recursos disponíveis dependem das permissões aprovadas pela plataforma.
